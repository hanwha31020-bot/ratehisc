# 금리 자동수집 대시보드

매일 한국시간(KST) 새벽 3시대부터 9개 금리를 자동으로 수집해서, GitHub Pages 웹사이트에서 확인할 수 있게 해주는 완전 무료 자동화입니다.

- 자동 실행: GitHub Actions (무료)
- 웹사이트 호스팅: GitHub Pages (무료)
- 별도 서버/결제 없음

## 수집 항목 (9개)

1. 한국은행 기준금리
2. CD(3개월)
3. A1CP(1개월)
4. A1CP(3개월)
5. 회사채(AA-, 1년)
6. 회사채(AA-, 2년)
7. 회사채(AA-, 3년)
8. 국고채권(3년)
9. SOFR

이 밖에 화면에는 **콜금리(콜시작금리+10bp)** 가 회사채(AA-,3년)와 국고채권(3년) 사이에 함께 표시됩니다 (한국자금중개 PDF에서 별도 수집, 아래 "콜시작금리 자동 수집" 참고).

## 폴더 구조

```
scripts/                 수집 스크립트 (Python)
  date_utils.py           영업일/전영업일 계산
  storage.py              이력(JSON) 저장 로직
  export_xlsx.py          이력을 엑셀로 변환
  fetch_rates.py          메인 실행 스크립트
  fetch_call_start.js     콜시작금리 수집 (KMB 일일 PDF, Node)
  sources/                사이트별 수집 모듈 (bok, kofia, sofr)
  tests/                  네트워크 없이 돌아가는 단위 테스트
docs/                    GitHub Pages로 배포되는 웹사이트
  index.html              대시보드 페이지
  data/history.json       누적 수집 이력 (자동 갱신)
  data/history.xlsx       누적 이력 엑셀 (자동 갱신)
  data/call_start.json    날짜별 콜시작금리 (KMB PDF에서 자동 수집)
.github/workflows/
  fetch-rates.yml         매일 자동 실행 워크플로우
```

## 배포 방법 (터미널/관리자 권한 전혀 필요 없음, 웹브라우저만 사용)

이 프로젝트는 컴퓨터에 아무것도 설치하지 않고, 웹브라우저에서 GitHub 사이트만 클릭해서 100% 배포할 수 있습니다.

### 0. 압축 풀기 + 숨김 파일 보이게 설정
1. 받은 `rates-tracker.zip`을 더블클릭(또는 우클릭 → 압축 풀기)해서 압축을 풉니다. (관리자 권한 불필요, 운영체제 기본 기능)
2. 이 프로젝트에는 `.github`, `.gitignore` 처럼 **점(.)으로 시작하는 폴더/파일**이 있는데, 기본 설정에서는 파일탐색기에 안 보일 수 있습니다. 업로드 전에 숨김 파일이 보이도록 설정해주세요.
   - **Mac**: 압축 푼 폴더를 Finder에서 연 상태에서 `Cmd + Shift + .` (마침표) 를 누르면 숨김 파일이 나타납니다.
   - **Windows**: 탐색기 상단 **보기(View)** 탭 → **숨긴 항목(Hidden items)** 체크박스 선택.
   - `.github` 폴더와 `.gitignore` 파일이 회색으로 흐릿하게 보이면 정상입니다 (선택은 정상적으로 가능).

### 1. GitHub 저장소 만들기
1. 브라우저에서 https://github.com/new 접속 (로그인 필요)
2. Repository name에 원하는 이름 입력 (예: `rates-tracker`)
3. Public/Private 아무거나 선택 (Public이 Actions 무료 사용량이 더 넉넉합니다)
4. 다른 옵션은 그대로 두고 **Create repository** 클릭

### 2. 파일 업로드
1. 방금 만든 저장소 페이지에서 **Add file → Upload files** 클릭
2. 압축 푼 `rates-tracker` 폴더를 **열고**, 그 안의 내용물 전체(`.github`, `docs`, `scripts`, `README.md`, `requirements.txt`, `.gitignore`)를 **모두 선택(Ctrl+A / Cmd+A)** 한 뒤, 브라우저의 업로드 영역으로 통째로 드래그합니다.
   - 주의: `rates-tracker` 폴더 자체를 드래그하지 말고, 그 **안의 내용물**을 드래그해야 합니다. (폴더째 올리면 `rates-tracker/scripts/...` 처럼 한 단계 더 들어간 구조가 되어버립니다)
3. 파일 목록이 다 올라온 게 보이면 하단의 **Commit changes** 클릭
4. 업로드 후 저장소 파일 목록에 `.github` 폴더가 보이는지 꼭 확인하세요. 안 보이면 0번의 숨김 파일 설정이 안 된 것이니 `.github/workflows/fetch-rates.yml` 파일 하나만 아래 방법으로 별도 생성하면 됩니다:
   - 저장소 페이지 **Add file → Create new file** 클릭
   - 파일명 입력칸에 `.github/workflows/fetch-rates.yml` 이라고 입력 (슬래시를 입력하면 자동으로 폴더가 만들어집니다)
   - 압축 푼 폴더 안의 `.github/workflows/fetch-rates.yml` 파일을 메모장/텍스트에디터로 열어서 내용을 복사한 뒤, GitHub 편집창에 붙여넣기
   - **Commit changes** 클릭

### 3. GitHub Pages 활성화
1. 저장소의 **Settings → Pages** 로 이동
2. "Build and deployment" → Source를 **Deploy from a branch** 로 설정
3. Branch는 **main**, 폴더는 **/docs** 선택 후 저장
4. 몇 분 후 `https://<내계정>.github.io/<저장소이름>/` 주소로 사이트가 열립니다.

### 4. Actions 쓰기 권한 설정 (자동 커밋을 위해 필요)
1. 저장소의 **Settings → Actions → General** 로 이동
2. 맨 아래 "Workflow permissions" 에서 **Read and write permissions** 선택 후 저장

### 5. 첫 실행 테스트 (수동 실행)
1. 저장소의 **Actions** 탭 → 왼쪽에서 "Fetch daily rates" 선택
2. 오른쪽 "Run workflow" 버튼 클릭 → 실행
3. 실행이 끝나면 초록색 체크가 뜨는지 확인합니다. 만약 실패(빨간 X)하면 로그를 열어서 어떤 항목이 실패했는지 확인하세요.
4. 성공하면 `docs/data/history.json`, `docs/data/history.xlsx` 가 자동으로 커밋됩니다.
5. Pages 사이트를 새로고침하면 오늘자 금리가 표시됩니다.

이후로는 매일 KST 새벽 3시대부터 30분 간격으로 7시 전까지(3:07, 3:37, 4:07, 4:37, 5:07, 5:37, 6:07, 6:37, 6:52) 자동으로 실행을 시도합니다 (GitHub Actions의 예약 실행은 정각/30분 회차가 특히 많이 스킵되고 20~40분씩 밀리기도 해서, 분을 어긋나게 잡고 일찍부터 여러 번 반복합니다 - 먼저 성공하면 이후 시도는 변경 사항이 없어 조용히 끝납니다). 이 7시 전 시도들과 별개로 월~금 KST 10:37에 한 번 더 돌아 아침에 교체된 콜 PDF를 반영합니다 (아래 "콜시작금리 자동 수집" 참고). 스케줄 시각을 바꾸고 싶으면 `.github/workflows/fetch-rates.yml`의 `cron` 값을 수정하세요. UTC 기준이라 KST보다 9시간 빠릅니다.

혹시 예약 실행이 둘 다 놓쳐서 오늘자가 안 들어왔다면, 사이트 상단의 **"지금 값 갱신하기"** 링크로 바로 이동해서 **Run workflow**를 눌러 즉시 채울 수 있습니다 (GitHub 로그인 필요).

## 꼭 확인해야 할 점 (중요)

- **KOFIA(CD/CP/회사채/국고채권) API**: 브라우저에서 실제 요청을 캡처해서 만들었지만, GitHub Actions 서버(쿠키 없는 첫 요청)에서도 동일하게 동작하는지는 실제로 한 번 돌려봐야 확실합니다. 1회차 수동 실행 결과를 꼭 확인해주세요.
- **날짜 로직**: 매일 실행 시점 기준 "전영업일(국내)/그 전영업일(해외)" 값을 조회하며, 공휴일 등으로 데이터가 없으면 자동으로 하루씩 더 앞으로 이동해서 찾습니다. `history.json`의 각 날짜는 **실행한 날짜가 아니라 그 값이 실제로 유효한 기준일**로 저장됩니다 (예: 9/7(월)에 실행하면 그 결과는 실제 조회 대상이었던 9/4(금) 밑에 저장되고, 9/7 자신의 값은 그 다음 영업일 실행에서 채워집니다). 금요일 값은 그 다음 토/일에도 자동으로 채워 넣습니다 (주말엔 새 시세가 없으므로 금요일 값이 곧 주말 값).

- **SOFR 발표 시차**: 뉴욕 연은은 해당일 SOFR를 "다음 미국 영업일 아침"에 공시합니다. 대상일 값이 아직 발표 전이면 전날 값으로 대신 채우지 않고 **"발표 전"(pending)으로 비워두며**, 발표되면 매 실행 때 최근 약 2주치 레코드의 SOFR를 공시 이력 기준으로 다시 맞춰 자동으로 채웁니다. 미국 휴일(예: 컬럼버스데이)엔 공시가 없으므로 직전 공시일 값을 쓰고, `기준일`에는 요청한 날짜가 아니라 그 값이 실제로 속한 날짜를 적습니다. 미국 휴일 달력은 `scripts/sources/sofr.py`에 있으며 2022~2026년 실제 공시 이력과 대조해 확인했습니다 (달력이 틀려도 "나중 날짜 값이 이미 공시됨"으로 보정되어 값이 영구히 비지는 않습니다).

## 과거 데이터 한 번에 채우기 (백필)

처음 시작할 때처럼 이력이 하루치밖에 없다면, 아래 방법으로 과거 영업일치를 한 번에 채울 수 있습니다 (터미널 필요 없음, GitHub Actions에서 실행).

1. 저장소의 **Actions** 탭 → 왼쪽에서 **"Backfill rates"** 선택
2. 오른쪽 **Run workflow** 클릭 → `days`에 채우고 싶은 영업일 수 입력 (기본값 22 = 약 한 달) → **Run workflow**
3. 완료되면 `docs/data/history.json`, `docs/data/history.xlsx`에 과거 영업일치가 추가로 커밋됩니다.

오늘자(가장 최근 영업일)는 매일 자동 실행되는 "Fetch daily rates" 쪽 몫이라 백필 대상에서 제외됩니다. 여러 번 실행해도 같은 날짜는 최신 결과로 덮어써질 뿐이라 안전합니다.

이 워크플로우는 매주 일요일(KST 오전 8시)에도 자동으로 한 번 더 실행되어, "Fetch daily rates"가 어느 날 예약 실행을 놓쳐 빠진 날짜가 생겼더라도 최근 22영업일 범위 안이면 자동으로 복구됩니다.

## 콜시작금리 자동 수집

시트의 콜금리(117)에 쓰는 **콜시작금리 = MAX(기준금리 + 3bp, REPO 시작금리 + 2bp)** 를 한국자금중개(KMB)가 매 영업일 게시하는 "콜 레포 시장 동향" PDF에서 읽어 `docs/data/call_start.json`에 저장합니다 (`scripts/fetch_call_start.js`, Node + pdf-parse).

- REPO 시작금리 = PDF 상단 "1. 지준시장 주요 지표"의 **레포(일반채)** 칸. `3.09%`처럼 한 값이거나 `3.04~3.14%`·`2.45%~2.73%`처럼 범위로 나오며, 범위일 때는 **하한**입니다. 기준금리도 같은 표의 "기준금리" 칸에서 읽습니다. 칸 위치(좌표)로 읽습니다.
- 2026-04-07~11-23의 시트 콜금리 155일과 대조해 전부 일치함을 확인했습니다 (`node --test scripts/tests/call_start.test.js`로 규칙·표기 형태 단위 테스트).
- 날짜는 PDF 본문이 아니라 게시 목록의 날짜를 씁니다 (본문 날짜에 오타가 있는 파일이 있음). 휴일엔 PDF가 없고 주말도 없으므로, 화면에서는 국내 금리의 기준일(CD 기준일)로 조회해 직전 영업일 값을 그대로 씁니다.
- "Fetch daily rates"와 "Backfill rates" 워크플로에 단계로 들어 있고, 이미 저장된 날짜는 다시 받지 않아 여러 번 실행돼도 무해합니다. KMB 접속이 막히거나 실패해도 금리 수집 결과는 그대로 커밋되고(`continue-on-error`), 이 경우 팝업의 콜시작금리 칸이 "수집 전"으로 나와 직접 입력하면 됩니다.
- KMB가 목록에 남겨두는 PDF는 2026-04-07 이후분이라 그 이전 날짜는 채울 수 없습니다 (시트에는 이미 값이 있음).
- **게시 시각과 "수집 전"**: PDF는 보통 해당 영업일 저녁(생성 시각 17:49~20:16 KST, 중앙값 19:10)에 올라와 다음 날 새벽·아침 실행 때는 이미 있습니다 (2026-04~11의 156일 중 152일). 다만 4일은 등록이 다음 영업일로 밀렸고(금요일분 3건이 월요일에 등록, 수요일분 1건이 목요일에 등록), 이런 날은 다음 영업일 아침에도 "수집 전"으로 보입니다. 이때는 틀린 값을 넣지 않고 빈 칸으로 두며(팝업에서 직접 입력 가능), 올라오면 이후 실행에서 자동으로 채워집니다.
- 또 9일(약 6%)은 전날 저녁 파일이 다음 날 아침(07:55~10:16)에 같은 첨부 번호로 다시 만들어져 교체됐습니다. 그래서 최근 3일은 실행할 때마다 다시 받아 값이 바뀌었는지 확인하고 바뀌면 갱신합니다 (월~금 10:37 실행이 이를 반영).
- 조회 화면(오늘 기준 금리, 날짜별 조회, 기간별 검색, CSV)에서는 이 자동값으로 만든 `call_rate`를 쓰며, 팝업에서 직접 고친 값은 조회 화면에 반영되지 않습니다.
- 콜금리 타일(오늘 기준 금리·날짜별 조회)에는 작은 "산출 근거" 버튼만 두고, 누르면 타일 위에 작은 카드가 떠서(타일 크기는 그대로) 산출 근거를 보여줍니다: `기준금리 3.00% + 3bp = 3.03`, `레포 시작 3.09% + 2bp = 3.11`(범위면 하한 표기), 둘 중 큰 값(초록색 "채택" 줄) = 콜시작금리, +10bp = 콜금리. 같은 버튼을 다시 누르거나 바깥을 누르거나 Esc로 닫습니다. 복사 팝업의 콜시작금리 칸에는 한 줄로 요약해서 보여줍니다.

## 웹사이트 기능

- 오늘 기준 금리 표시 (콜금리 포함 10개)
- 날짜를 입력해서 해당일의 9개 금리 조회
- 금리 종류 + 기간을 선택해서 해당 기간의 값 목록/최소/최대/평균 확인
- 누적 이력 엑셀(history.xlsx) 다운로드
- **클립보드 복사하기** ("오늘 기준 금리"와 "날짜별 조회" 카드 제목 옆 버튼 → 팝업): `금리정보.xlsx` 시트의 A~AI열 순서(날짜, 요일, 코드 100~119, 이어서 S~AI 변동내역 확인) 그대로 탭으로 구분한 한 줄을 클립보드에 복사합니다. S~AH는 시트와 같은 변동내역 수식(`=IF(C1416-C1415=0,"변동없음",C1416-C1415)`, 114~119는 `ROUND(,2)` 비교), AI는 `=COUNTIF(S1416:AH1416,"<>변동없음")`로 붙습니다. 서식 포함 복사(빨간 글자 옵션)로 붙이면 엑셀이 붙여넣은 칸의 조건부 서식을 지우기 때문에, 시트의 조건부 서식과 같은 색을 고정 서식으로 함께 싣습니다 (요일 토·일 빨간 배경, SOFR·미국2년은 토·일·월 노란 배경, 변동없음 회색 배경). 고정 색이라 값이 나중에 바뀌어도 색은 따라 바뀌지 않습니다. 날짜(A열) 배경색은 `#FFF2CC`입니다. 팝업에서 "엑셀용 복사"를 누르고 엑셀의 날짜(A열) 칸에 붙여넣기만 하면 됩니다. 팝업의 "붙여넣기 미리보기"에서 실제로 복사되는 내용(계산값 + 수식)을 먼저 확인할 수 있고, Esc·바깥 영역 클릭·× 로 닫습니다. "날짜별 조회"는 조회창에 입력된 날짜 기준입니다.
  - 날짜(A)와 요일(B)도 시트와 같은 수식(`=A1415+1`, `=TEXT(A1416,"AAA")`)으로 붙여넣어집니다. 날짜는 바로 윗행에 이어지는 값이라, 붙여넣는 행의 윗행이 전날 날짜여야 맞습니다.
  - 계산열 101·102·105·111·112·113은 값이 아니라 **시트와 같은 수식**(`=C1416+$D$2`, `=D1416+10`, `=G1416+$J$2` 등)으로 붙여넣어져 기존 수식이 유지됩니다. 수식에 행 번호가 필요해서 "붙여넣을 행"을 입력받는데, 시트가 달력 기준 하루 한 행이라 날짜로 자동 계산합니다 (기준: 2026-11-23 = 1415행, `DEFAULT_ROW_ANCHOR`). 시트에서 날짜를 건너뛰는 등 어긋나면 입력값을 고치세요 - 고친 값이 새 기준으로 저장됩니다. 행 번호를 비우면 계산열을 값으로 복사합니다.
  - 콜금리(117) = 콜시작금리 + 0.10 이고, 콜시작금리는 **자동 수집**됩니다 (아래 "콜시작금리 자동 수집" 참고). 입력칸에 값을 직접 넣으면 자동값 대신 그 값을 쓰고, 자동값이 아직 없으면(수집 전) 그 칸은 빈 칸으로 복사됩니다. 미국 2년(investing.com)은 자동 수집이 안 되어 입력칸에 직접 넣습니다 (investing.com은 이용약관상 자동 수집이 금지되어 있고 브라우저에서도 다른 사이트로의 직접 조회가 막혀 있어 "사이트 열기" 링크만 둡니다). 같은 기준일을 쓰는 행(토·일·월, 휴일)은 한 번만 입력하면 되고, 입력값은 그 브라우저에 저장됩니다.
  - **변경된 금리 빨간 글자** (기본 켜짐): 시트에서 직접 칠하던 규칙과 같이, 직전 행(전날, 주말 포함) 대비 값이 바뀐 칸(2자리 반올림 기준, 계산열은 바탕 금리가 바뀌면 같이)을 빨간 글자로 붙입니다. 빨간 글자는 서식 있는 복사(HTML)로만 전달되므로, 켜면 시트의 열별 서식(맑은 고딕 11·가운데·0.00·테두리·날짜 배경)도 함께 실어 붙여넣은 칸의 모양이 바뀌지 않게 합니다. 끄면 값과 수식만(텍스트) 붙여넣어 기존 서식을 그대로 둡니다. 서식 있는 복사의 수식은 엑셀 전용 속성(`x:fmla`, `xmlns:x`) 없이 셀 글자(`=C1416+$D$2`)로만 싣습니다 - 그 속성을 쓰면 엑셀이 붙여넣는 행만큼 참조를 통째로 밀어버려(1416행에 붙이면 `=C2831+$D$1417`) 수식이 틀어집니다. 미국 2년은 직전 행 값도 있어야 변경 여부를 판단하므로, 팝업의 "비교용" 칸(직전 행 마감값, 복사되지 않음)에 한 번 넣어 두면 저장되어 다음부터는 전날 입력한 값이 그대로 비교됩니다. 직전 값이 없으면 복사 직후 안내에 알려줍니다.
  - 월요일 레코드는 시트에 토·일 행이 따로 있어 토·일·월 3행을 한 번에 복사합니다 (체크 해제하면 월요일 1행만).
  - 비어 있는 값(미입력, "발표 전" 등)은 빈 칸으로 복사되고 복사 직후 안내가 표시됩니다.
