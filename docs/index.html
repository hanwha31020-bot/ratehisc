출처 안내
  • 한국은행 기준금리: 한국은행(BOK) 공식 발표 기준
  • CD(3개월) · A1CP(1개월/3개월) · 회사채(AA-) · 국고채권(3년): 금융투자협회(KOFIA) 채권정보센터 시가평가수익률, 4개 채권평가사(나이스피앤아이·한국자산평가·KIS자산평가·에프앤자산평가) 평균값
  • SOFR: 미국 뉴욕 연방준비은행(New York Fed) 공식 API
  • 콜금리(시작금리+10bp): 한국자금중개(KMB)가 매 영업일 게시하는 "콜 레포 시장 동향" PDF에서 읽은 값으로 산출합니다. 콜시작금리 = MAX(기준금리 + 3bp, 레포 시작금리 + 2bp)이고 여기에 10bp를 더한 값이 콜금리입니다. 레포 시작금리는 PDF 상단 지표표의 레포(일반채) 칸이며, 범위(예: 3.04~3.14%)로 나오면 하한을 씁니다. 계산에 쓴 각 값은 콜금리 카드의 "산출 근거" 버튼을 누르면 볼 수 있습니다. PDF는 보통 해당 영업일 저녁에 올라와 다음 날 아침에 반영되지만, 게시가 늦어지면 "수집 전"으로 표시됩니다.
각 금리는 실행일 기준 전영업일 값이며, 정확한 기준일은 카드 하단에 표시됩니다.
